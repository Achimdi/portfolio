# Chimdiume Azie: Portfolio

A multi-page portfolio for a software and AI/ML developer, served by GitHub Pages at
https://achimdi.github.io/portfolio/.

The published site is plain HTML, CSS and JavaScript. The pages are generated by a small Node
script with no dependencies, so there is nothing to install.

## Pages

| URL | File | What it is |
|---|---|---|
| `/portfolio/` | `index.html` | Home: hero with portrait, what I build, selected work, tools, about, contact |
| `/portfolio/projects/` | `projects/index.html` | All projects |
| `/portfolio/projects/<slug>/` | `projects/<slug>/index.html` | Case studies: `neuroscan-ai`, `tallybox`, `nellow`, `twzee-foods` |
| `/portfolio/about/` | `about/index.html` | Background, approach, interests, tools |
| `/portfolio/contact/` | `contact/index.html` | Email (Gmail, email app or copy), socials, message form, work with me |
| any missing path | `404.html` | Styled "page not found" (GitHub Pages serves it automatically) |
| `/portfolio/services.html` | `services.html` | Old address; redirects to Contact → Work with me |

Every page is a real file in its own folder, so visitors can open or refresh any URL directly.

## Edit content, then build

All text, facts, links and image lists live in **`src/data.mjs`**. Change it there, then run:

```bash
node src/build.mjs
```

This rewrites the HTML pages, `sitemap.xml`, `robots.txt`, `services.html` and the technology
logo sprite (`assets/icons/tech.svg`). Commit the generated files together with your change.

| File | Purpose |
|---|---|
| `src/data.mjs` | Content: site details, projects, skills, about, services |
| `src/templates.mjs` | Components and page templates (header, footer, cards, case study…) |
| `src/icons.mjs` | Interface icons, the CA monogram, and the technology-logo sprite |
| `src/build.mjs` | Writes every page into the repository root |
| `src/icons/tech/` | Technology logos from Simple Icons (CC0), inlined into the sprite at build time |
| `assets/css/site.css` | The one stylesheet: tokens, components, pages, motion |
| `assets/js/site.js` | Menu, scroll reveals, contents highlight, copy email, contact form, Grad-CAM slider, video fallback |

Links use relative paths (`../`, `../../`), so the site works under `/portfolio/` on GitHub Pages
and at the root of a local server. Only `404.html` uses absolute `/portfolio/` links, because
GitHub Pages can serve it at any depth.

## Preview locally

```bash
python -m http.server 8000
```

Run it in this folder and open http://localhost:8000. Python's server cannot seek inside videos
(no range requests); GitHub Pages can.

## Design system

- Colours: midnight `#080B12`, deep navy `#101827`, blue slate `#172D4A`, electric blue `#398BFF`,
  soft violet `#9875FF`, text `#F1F5FA`, secondary text `#AAB7CA`. Each case study adds one accent.
- Type: Space Grotesk (headings), Inter (body), JetBrains Mono (labels). All self-hosted in
  `assets/fonts/` under the SIL Open Font License (licence files alongside).
- Motion: one hero load sequence (the portrait "scan"), one-time scroll reveals, hover states and
  cross-page view transitions. All of it is off when the visitor asks for reduced motion.

## Deploying (GitHub Pages)

Pages publishes the root of the `main` branch. There is no workflow and no build on GitHub.

1. Push the branch: `git push -u origin portfolio-v3` (this does not change the live site).
2. To go live, fast-forward main: `git push origin portfolio-v3:main`. The site updates in about a minute.
3. The previous versions are kept: tag `v1-live` (the original site) and branch `portfolio-v2`.
   To roll back, push one of them to main, for example `git push --force origin portfolio-v2:main`.
